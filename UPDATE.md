# Обновление Вектор 3.0

## Что изменилось

- Новый тип «Привычка»: ежедневная отметка и её отмена, календарь по месяцам, серия сейчас, лучшая серия и регулярность.
- Быстрая отметка прямо в карточке привычки. В подробной карточке календарь и отметка находятся перед часами.
- Главный экран компактнее на телефоне: уменьшены заголовок, сводка и отступы.
- Проценты целей означают выполнение шагов; проценты привычек — выполнение плана по дням. Регулярность показывается отдельно и учитывает только уже наступившие дни.
- Одинаковые обратные отсчёты не дублируются. Основные часы прошедшего времени сохранены.
- Ежедневные отметки включены в статистику за неделю и историю.

## Как обновить

1. В действующем приложении «Настройки → Экспорт данных» сохраните резервную копию.
2. Распакуйте `vector-update-v3.zip`.
3. Откройте существующий репозиторий `shahvdele/vector-mini-app`, затем **Add file → Upload files**.
4. Перетащите содержимое распакованной папки: `dist/`, `tests/`, `package.json`, `preview.mjs`, `README.md`, `UPDATE.md`. Пути в списке должны начинаться с `dist/...` и `tests/...`, без лишней внешней папки.
5. Нажмите **Commit changes**. Существующий `.github/workflows/pages.yml` загружать повторно не нужно.
6. Дождитесь зелёной отметки в **Actions**. Закройте Mini App полностью и откройте заново. В настройках должна появиться версия **3.0**.

URL GitHub Pages, кнопка бота и CloudStorage остаются прежними. Старые записи автоматически считаются целями. Для ежедневного спорта откройте существующую цель → **Изменить → Что создаём? → Привычка**. Ранее созданные шаги сохранятся. Предыдущие ежедневные выполнения не выдумываются: календарь начинает наполняться с ваших новых отметок.
